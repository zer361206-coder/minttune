# MintTune 🎵

Pemutar musik desktop native modern untuk Linux Mint (dibangun dengan Python 3.11+ dan PyQt6).

## Fitur Utama
- Desain Bento Modern ala Dribbble dengan kartu membulat.
- Integrasi Tema Linux Mint (otomatis ikut Dark/Light mode & Accent Color).
- Manajemen Folder Whitelist & Blacklist.
- Format Lengkap (MP3, FLAC, M4A, WAV, OGG, OPUS).
- Smart Playlist (Lagu Favorit & Sering Diputar), Antrean Lagu, dan Ekspor/Impor M3U.

## Cara Menjalankan dari Source
1. Clone repositori ini:
   git clone https://github.com/USERNAME_KAMU/minttune.git
2. Masuk ke folder:
   cd minttune
3. Beri izin dan jalankan instalasi:
   chmod +x install.sh
   ./install.sh

Setelah instalasi selesai, MintTune bisa langsung dibuka dari Menu Aplikasi Linux Mint atau ketik minttune di terminal.
